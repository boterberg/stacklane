# v1.4.0.0: Managing together

<ReleaseMeta />

[Lees dit in het Nederlands](/releases/v1.4.0.0)

This version also came from conversations with hosters. They wanted the panel in their own style, they work with a team, and their customers run game servers together.

## Your own theme

Under **Admin → Settings → Brand and theme** you pick a ready-made theme, or set the accent colour, the greys and the corners yourself. You see every change right away; customers see it once you save. To go further, add your own CSS under **Custom CSS**. See [Branding](/docs/guides/branding).

## Staff with their own permissions

Under **Admin → Team** you add staff and choose what they may do: support, billing, customers, or services and products. A staff member only sees those parts in the menu. The server checks every request again. Settings, integrations, the mail log, updates and the team itself stay with administrators. See [Team and permissions](/docs/guides/team).

## Sharing game servers

A customer invites others from the **Users** tab on the server. They accept under **Account → Shared access** and only get the permissions that were ticked. Whoever shares the server sees in the activity log who did what. Guests see no IP addresses there.

## Plugins and mods

Minecraft servers have a **Plugins and mods** tab. Customers search Modrinth, only for what fits their server type and Minecraft version, and install in one click. Stacklane only accepts files from Modrinth itself. See [Game servers](/docs/guides/gameservers#plugins-en-mods).

## Updating

Update from **Admin → System** or with `sudo stacklane update`. The database gets a column for permissions and a table for shared game servers; that happens by itself. Existing administrators stay administrators. For plugins and mods your server needs to reach `api.modrinth.com`.
