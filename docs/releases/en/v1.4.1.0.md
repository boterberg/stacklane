# v1.4.1.0: Locked down tighter

<ReleaseMeta />

[Lees dit in het Nederlands](/releases/v1.4.1.0)

After 1.4.0.0 we had Stacklane thoroughly audited again. Nothing critical came out of it, but there was a set of gaps we did not want to leave open. They are all closed, each with a test that checks it stays that way.

You will notice two things yourself. A link to confirm your email address now asks you to sign in first, if you were not already. And scripts with an API token can do less than before: anything that gives access to a server or moves things between servers is now done in the panel. The [API guide](/docs/guides/api) says exactly what can and cannot be done.

Update as always with `stacklane update`. There are two small database changes, which run by themselves.
