# v1.4.1.1: Updater kept apart from the panel

<ReleaseMeta />

[Lees dit in het Nederlands](/releases/v1.4.1.1)

A small update with three improvements that came out of talks with hosters.

Updating from the panel already worked without root rights for the panel itself. Now the updater no longer looks in the folder where the panel leaves its request either. It takes the version to install from the signed package source, and writes its progress to `/var/lib/stacklane-update`. [Updating](/docs/installation/updating) explains how it works.

Does Proxmox still use its own certificate? Paste `/etc/pve/pve-root-ca.pem` into the new field of the connection, and the check no longer has to be off. See the [VPS guide](/docs/guides/vps).

Update as always with `stacklane update`. There are no database changes.
