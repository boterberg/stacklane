# v0.0.1.0: de eerste versie

<ReleaseMeta />

Dit is waar Stacklane mee begint. Klanten kunnen een account aanmaken, hun dashboard bekijken en vragen stellen via tickets. Je supportteam beantwoordt die vanuit één inbox.

## Wat er in zit

Het klantpanel heeft een zijbalk met de onderdelen die al werken en de onderdelen die eraan komen. Met <kbd>Ctrl</kbd>+<kbd>K</kbd> spring je naar elke pagina, en op een telefoon schuift het menu uit vanaf de zijkant. Licht of donker volgt de instelling van je systeem.

Tickets horen bij een afdeling. Een klant kan opmaak, lijsten en links in een bericht zetten; de server haalt er alles uit wat niet veilig is. Reageert een klant op een gesloten ticket, dan gaat het weer open. Beheerders zien onder **Beheer** de tickets van iedereen, reageren als support en zetten de status.

## Installeren en bijwerken

Stacklane komt als Debian-pakket uit de pakketbron op stacklane.io. `sudo stacklane setup` zet een nieuwe server klaar en `sudo stacklane update` maakt eerst een back-up van de database voordat het bijwerkt. Hoe je de pakketbron toevoegt, lees je bij [Installeren](/docs/installation/install).

## Nog niet

Facturatie, VPS, gameservers, domeinen en webhosting zitten nog niet in deze versie. Ze staan op de [roadmap](/#roadmap).
