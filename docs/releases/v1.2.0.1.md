# v1.2.0.1: Een volle demo

<ReleaseMeta />

[Read this in English](/releases/en/v1.2.0.1)

Een kleine update voor de [demo](https://demo.stacklane.io/login). Na 1.2.0.0 lukte inloggen daar soms niet, omdat op de demo `PUBLIC_URL` niet was ingesteld. Dat is opgelost, en Stacklane waarschuwt nu bij het starten als die instelling ontbreekt.

De demo laat nu ook zien wat er in 1.2 bij kwam. De demoklant heeft twee servers met grafieken, snapshots en firewallregels, een volume, een floating IP, een privénetwerk, ISO's, SSH-sleutels, twee domeinen en een collega met gedeelde toegang. Acties op de servers voert de demo niet echt uit.

Voor je eigen installatie verandert er niets, behalve de waarschuwing bij een ontbrekende `PUBLIC_URL`.
